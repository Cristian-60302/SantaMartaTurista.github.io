Caribe Colombiano Vivo

Una guia turistica y comunitaria para conocer destinos del Caribe colombiano, guardar lugares visitados y compartir resenas utiles con otros viajeros.

No somos una agencia: somos una guia de viaje.

El proyecto nacio para mostrar que el turismo no se reduce a vender planes. La pagina presenta lugares, memoria, cultura, naturaleza y recomendaciones reales para que cada visitante pueda armar su propio recorrido.

Santa Marta sigue siendo parte central del sitio, pero ahora el mapa se amplia hacia Cartagena, La Guajira, Palomino, Barranquilla, Mompox, San Andres y Providencia. La idea es reconocer el Caribe colombiano como una region diversa, no como un solo destino.

La bitacora de usuario permite iniciar sesion, marcar lugares visitados y dejar resenas. En esta version para GitHub Pages los datos se guardan en el navegador; para produccion se puede conectar a Neon mediante una API segura.
